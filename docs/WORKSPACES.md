# Workspaces

Each enabled category is its own workspace. Software and University never share an undifferentiated project list.

## Software

Answers: what am I building, what needs doing, what changed, how do I launch it?

Capabilities include Git, GitHub, commands, languages/frameworks, versions, VS Code, and terminal.

## University

The UI says **Courses**, not projects.

Answers: what am I studying, how long, which topics, which exams, how am I performing?

Study time and attendance are separate. GPA uses the **stored final grade**, not the best exam attempt.

## Generic (Fitness, Photography, Personal, custom)

Title, description, folder, primary file, links, files, TODOs, time, XP, achievements, activity. No Git/VS Code/exam chrome unless you later add a specialized kind.

## Capabilities

The app checks a capability set (`git`, `exams`, `todos`, …), not `if category === "software"` in the UI. Custom categories cannot enable exam/Git tables; those require a dedicated kind.
